# PS2 Controller ROS 2 Teleoperation Package for TurtleBot3 (Wired Version)

이 패키지는 유선 PS2 컨트롤러(게임패드)를 사용하여 라즈베리파이4 환경에서 TurtleBot3 Burger 로봇을 원격 조종할 수 있게 해주는 ROS 2 Humble 패키지입니다.

물리적 핀 매핑 충돌 해결, 통신 타이밍 최적화, 2차 감도 곡선 조작 필터 및 버튼 하나로 주 도메인(ROS_DOMAIN_ID)을 변경하는 실시간 핫 리로드 기능이 포함되어 있습니다.

---

## 1. 하드웨어 연결 구성 (라즈베리파이 ↔ 어댑터 보드)

유선 PS2 어댑터 보드 제조사에 따라 **MISO와 MOSI 라벨이 실제 통신 신호 상에서 서로 뒤바뀌어 있는 문제**를 방지하기 위해 소프트웨어 드라이버 수준에서 스왑 처리가 반영되어 있습니다.

아래의 **새로운 일반 GPIO 물리 핀 배치**대로 선을 연결해 주세요:

| 어댑터 보드 라벨 | 라즈베리파이 물리 핀 번호 | GPIO 번호 (BCM) | 역할 |
|:---|:---|:---|:---|
| **SS** | **11번 핀** | GPIO 17 | ATT (어텐션 / 선택) |
| **CLK** | **13번 핀** | GPIO 27 | CLK (클럭) |
| **MISO** | **15번 핀** | GPIO 22 | CMD (명령 출력 - 코드에서 CMD로 매핑) |
| **MOSI** | **16번 핀** | GPIO 23 | DAT (데이터 입력 - 코드에서 DAT로 매핑) |
| **GND** | **6번 핀** | GND | 접지 |
| **5V** | **2번 또는 4번 핀** | 5V | 전원 |

## 2. 파일 목록 및 설명

* **`start_ps2_teleop.sh`** (쉘 스크립트):
  * 최상위 래퍼 실행 스크립트입니다. 노드가 도메인 변경 신호(종료 코드 `100`)를 보낼 때 환경 변수(`ROS_DOMAIN_ID`)를 스왑하여 **1초 내에 노드를 자동 재실행**시킵니다.
* **`test_ps2_raw.py`** (파이썬 독립 테스트):
  * ROS 2를 구동하지 않고 하드웨어 수준에서 조이스틱과 버튼 입력 신호가 정상 파싱되는지 실시간 모니터링하기 위한 독립 테스트 파일입니다.
* **`ps2_teleop/`** (ROS 2 패키지):
  * **`ps2_driver.py`**:
    * PS2 SPI 통신 드라이버입니다. 리눅스 OS 스케줄러로 인한 타이밍 지터(Jitter)를 차단하기 위해 **클럭 루프 내의 모든 `time.sleep` 지연을 제거하고 무부하 동기 통신으로 최적화**하여 100% 수신율을 제공합니다.
  * **`ps2_teleop_node.py`**:
    * 메인 ROS 2 노드입니다. 조이스틱 신호를 파싱하여 `/cmd_vel` 토픽으로 발행하며, 패드 방향키 제어 및 2차 감도 곡선($y = x \times |x|$), 가속 필터링이 구현되어 있습니다.
  * **`ps2_teleop_node_single.py`** (백업):
    * 이중 도메인 발행 기능 이전의 안정적인 단일 도메인 노드 원본 백업 파일입니다.

## 3. 조작 방법

### A. 주행 및 스티어링
* **D-pad 방향키 (좌측 4개 방향 버튼):** 누르는 동안 각 방향별 **최대 설정 속도**로 즉시 주행하며, 손을 떼면 부드럽게 감속하여 멈춥니다.
* **왼쪽 아날로그 조이스틱:** **안전 버튼(L1/R1) 조작 없이** 단독으로 전/후진 및 회전 속도를 정밀하게 제어하는 Arcade Drive 조종 모드입니다.
  * **상/하 (LY):** 전진 / 후진 (2차 감도 포물선 적용으로 미세 조종 수월)
  * **좌/우 (LX):** 좌/우 회전 (조향 방향 반전 처리 완료)

### B. 도메인 ID 및 속도 동적 변경
* **세모 (Triangle - 위쪽 버튼):** 활성 `ROS_DOMAIN_ID`를 즉시 **`22`**로 변경하고 노드를 자동 재시작합니다.
* **엑스 (Cross/X - 아래쪽 버튼):** 활성 `ROS_DOMAIN_ID`를 즉시 **`17`**로 변경하고 노드를 자동 재시작합니다.
* **동그라미 (Circle/O - 우측 버튼):** 로봇 최대 속도 제한을 `+0.05 m/s` 늘립니다. (회전 속도 제한도 비율에 맞춰 함께 상향)
* **네모 (Square - 좌측 버튼):** 로봇 최대 속도 제한을 `-0.05 m/s` 줄입니다. (회전 속도 제한도 비율에 맞춰 함께 하향)

---

## 4. 구동 명령어

라즈베리파이 터미널에서 다음 명령어를 실행합니다:

```bash
# 쉘 스크립트 실행 (환경 변수 소싱 및 모델 세팅 자동 수행)
bash ~/start_ps2_teleop.sh
```

동작 중 종료를 원하시면 터미널 창에서 **`Ctrl + C`**를 누르면 쉘 래퍼까지 깨끗하게 완전 종료됩니다.
